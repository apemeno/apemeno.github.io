?Cara export dari SAP2000
  1. Display → Show Tables (Ctrl+T), centang:
    • Analysis Results → Frame Output → Element Forces - Frames
    • Model Definition → Frame Assignments → Frame Section Assignments
    • Design Data → Concrete Design 1 – Column / Beam Summary
    • Opsional: Connectivity - Frame + Joint Coordinates (deteksi balok/kolom otomatis)
  2. Pilih kombinasi di Select Load Patterns/Cases.
  3. File → Export All Tables → To Excel, lalu unggah ke sini.
Tanpa tabel konektivitas, tipe elemen ditebak dari nama penampang (K…/C…/KOL… = kolom). Bisa diubah di tab Detail.
